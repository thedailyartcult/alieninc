# Panteon Research Institute — AGENTS.md

## This folder is the research institute landing + article publishing system

### Structure

```
panteon-research-institute/
├── index.html              ← Landing page (auto-generated by publish.py)
├── mission-and-vision.html ← Founding charter (hand-edited)
├── publish.py              ← Article publisher (run: python3 publish.py)
├── article-template.md     ← Copy this, fill it, drop in source/
├── articles/               ← Generated HTML articles (DO NOT hand-edit)
├── source/                 ← Drop .md files here to publish
└── AGENTS.md               ← This file
```

### How to publish an article

publish.py supports BOTH styles automatically (detected per-file):

**Style A — bare writing (preferred):** just write the essay, no front-matter.
Defaults are filled in: tag "Panteon Research Institute", date = today, author
"Patrick Neil A.", slug auto-generated from the title. The first `#` is the
title (consumed) and `##` renders as h2, `###` as h3.

**Style B — YAML front-matter:** provide title/slug (required) plus optional
tag, date, author:
   ```
   ---
   title: The Article Title
   tag: Panteon Research Institute
   date: 2026-08-02
   author: Patrick Neil A.
   slug: the-article-title
   ---
   ```
In front-matter mode the classic offset applies: `#` → h2, `##` → h3.

Steps:
1. Drop a `.md` file in `source/` (either style)
2. Run: `python publish.py` (publishes all) or `python publish.py my-article.md` (publishes one)
3. The script generates `articles/{slug}.html` and regenerates `index.html`
4. Commit and push

### Markdown syntax supported

- `# Heading` → article title (bare mode) or h2 (front-matter mode)
- `## Subheading` → h2 (bare mode) or h3 (front-matter mode)
- `> quote` → pull-quote blockquote (dark style with accent border)
- `**bold**` → strong
- `*italic*` → em
- `` `code` `` → inline code
- `[text](url)` → link
- `- item` / `1. item` → ul / ol lists
- `---` → dark section divider (switches to dark background)

### Design language (MANDATORY)

- Same header, footer, brand SVG as all Panteon pages
- Inter font only (Google Fonts)
- CSS variables from `../styles.css`
- Hero: `.cap-hero` with animated line + fade-up
- Articles: `.article-body` with scroll-reveal paragraphs
- Dark sections: `.dark-section` with left-border accent
- Pull quotes: `.pull-quote` with `#9ab4c1` left border
- Closing: `.closing-section` with vertical line + CTA

### Forbidden

- NO new fonts, colors, or layouts
- NO different footer or header structures
- NO hand-editing files in `articles/` (they are auto-generated)
- NO editing `index.html` by hand (it is regenerated by publish.py)
