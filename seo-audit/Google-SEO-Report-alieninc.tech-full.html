1. Executive Summary

This report presents a comprehensive SEO audit of alieninc.tech for a Multi-company operating group / AI infrastructure (corporate umbrella) site, generated on October 17, 2026. Findings combine technical, content, schema, performance, visual, and search-readiness evidence as available.

74/100
SEO Health Score
Critical Issues Found:
  1. Homepage + article index are well-structured with valid Organization schema, 868 words, 96/100 content quality, and solid security headers
  2. 120 of 357 sitemap URLs lack a canonical tag; 115 lack Open Graph and Twitter Card meta
  3. 112 pages have no meta description; 46 pages have no H1
  4. llms.txt returns 404 — Lighthouse agentic readiness drops the audit
  5. robots.txt deliberately blocks 10+ AI crawlers (GPTBot, CCBot, PerplexityBot, Google-Extended), contradicting GEO/AI-search goals
Quick Wins:

  3. Add meta description + canonical + OG/Twitter tags to the 115 pages that lack them (extend tools/inject-seo.py pattern to non-subdomain pages)
  4. Remove or fix the /trust/index.html 404 in the sitemap
  5. Set logo.png alt to a meaningful value (e.g. 'Alien Inc logo') or alt="" if purely decorative

2. Audit Categories

2.1 Technical SEO

Score: 78/100

What Works

  • sitemap.xml found and serving 357 URLs (urlset format)
  • robots.txt reachable, well-commented, blocks admin/api/vault paths
  • 356/357 URLs return 200; proper 404 page with noindex for unknown URLs
  • HTTPS + HSTS preload, CSP, X-Frame-Options DENY, nosniff
  • Cloudflare + Fastly CDN caching in front

Findings

120 pages missing canonical High

Crawl of 357 sitemap URLs found 120 without <link rel=canonical>.

Recommendation: Self-referencing canonical on every page; extend tools/inject-seo.py beyond the 8 subdomains.

Sitemap lists a 404 URL Medium

https://alieninc.tech/trust/index.html returns 404 but is in the sitemap.

Recommendation: Remove from sitemap.xml or restore the page.

Duplicate titles Low

articles/2026/09/24/The-Alien-Minds-We-Built.html and articles/2026/09/24/index.html share the same title/description; panteon login.html and secure.alieninc.tech also share 'Panteon — Secure Portal'.

Recommendation: Canonicalize one variant per pair.

2.2 Content Quality

Score: 92/100

What Works

  • Homepage: 868 words, quality 96/100 (filler 0, AI-pattern 0, density 1.00)
  • Strong E-E-A-T signals: founder page, founding date, legal name, named founder in schema
  • Specific, verifiable claims (compliance frameworks, founding date 2016-12-22)

Findings

112 pages missing meta description High

31% of indexed pages have no meta description, forcing Google to auto-generate snippets.

Recommendation: Write 120-155 char descriptions for all key pages; automate via inject-seo.py.

46 pages missing H1 Medium

Mostly panteon.alieninc.tech subpages (yono-forge, pipeline-builder, cmb-* pages).

Recommendation: Add a unique H1 to each page.

2.3 On-Page SEO

Score: 70/100

What Works

  • Homepage has canonical, OG, Twitter Card, Organization JSON-LD
  • Title tag is clear and branded: 'Alien Inc. – Guardian of Philippine Digital Infrastructure'
  • Single H1 on homepage (good hierarchy)

Findings

115 pages missing Open Graph Medium

No og:title/og:image on 32% of pages — poor social/LinkedIn/Facebook preview control.

Recommendation: Add OG + Twitter Card tags site-wide.

logo.png alt='•' on every page Low

Brand logo uses a bullet as alt text — bad accessibility and a missed image-SEO signal.

Recommendation: Use alt="Alien Inc" or alt="" (decorative).

2.5 Performance (CWV)

Score: 70/100

What Works

  • Served via Cloudflare + Fastly, gzip, cached edges in MNL
  • Static HTML (no SPA shell detected), no JS render required for primary content
  • Cache-Control: max-age=600 + Age header present

Findings

No CrUX/PSI field data collected Info

Google PageSpeed/CrUX APIs require an API key that isn't configured, so lab/field CWV were not measured.

Recommendation: Configure GOOGLE_API_KEY to enable pagespeed_check.py for real INP/LCP/CLS numbers.

Fonts loaded from Google Fonts with preconnect Info

fonts.googleapis.com + fonts.gstatic.com render-blocking CSS.

Recommendation: Self-host fonts or add font-display: swap to protect LCP.

2.6 AI Search Readiness

Score: 55/100

What Works

  • Primary content readable without JavaScript (agentic_check P0 pass)
  • robots.txt reachable; unknown URLs return real 404
  • WebMCP tools annotated on forms (P2 info)
  • Content-Signal preference declared

Findings

llms.txt returns 404 High

/llms.txt is not published. Lighthouse drops the agentic-readiness audit from its fraction; publishing one adds a counted pass.

Recommendation: Publish /llms.txt with an H1, a '>' summary, and markdown links to all 7 company portals and key pages.

robots.txt blocks 10+ AI crawlers High

GPTBot, CCBot, Google-Extended, anthropic-ai, Claude-Web, cohere-ai, PerplexityBot, Bytespider, Diffbot are all Disallowed. Blocking an AI search crawler removes the site from that engine's answers.

Recommendation: Confirm intentional. If GEO/AI Overviews visibility is a goal, allow Google-Extended and PerplexityBot; keep training bots (GPTBot/CCBot/Bytespider) blocked if desired.

ai-catalog.json / A2A agent card absent Info

Agentic Resource Discovery and A2A agent card endpoints are not present (na).

Recommendation: Consider publishing /ai-catalog.json and /.well-known/agent-card.json to be discoverable by AI agents.

2.7 Images
