Capabilities

Built for the way AI actually works

Every feature is designed around one problem: AI agents waste tokens re-reading context they already have. CMB stops that.

Token-Budgeted Recall

Ask for "512 tokens about the nginx config" and get exactly that — a packed context window with hard budget enforcement, not a file dump.

Semantic Search

Hybrid vector + lexical retrieval finds the memory you mean — not just the one that matches a keyword. 384-dim embeddings over every stored fact.

Session Handoff

End a session with a compact summary and open threads. The next session starts with that context injected — no 450K-token transcript resume.

Bi-Temporal History

Every correction keeps its history. Ask "what did we believe three months ago?" and CMB shows every version of a fact, when it was true, and what replaced it.

Grounded Answers

CMB answers only from what it actually remembers — with citations. When evidence is thin it says "insufficient evidence" instead of guessing.

Governance & Audit

Hash-chained operation receipts, bi-temporal corrections, pinning, and scoped visibility (session → repo → workspace) keep memory trustworthy.
