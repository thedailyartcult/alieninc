MCP Tool Reference — 31 × cmb_*

CMB exposes 31 tools over MCP (stdio). All tool names are prefixed cmb_. Every tool accepts flat JSON parameters. The list below is grouped by function.

Store & Recall

ToolPurpose
cmb_rememberStore a durable fact (semantic/episodic/procedural).
cmb_recallRetrieve relevant memories (full bodies).
cmb_recall_contextRetrieve memories packed into a hard token budget (recommended).
cmb_recall_groundedAnswer strictly from memory, with citations — or abstain.
cmb_answerBackward-compatible alias for cmb_recall_grounded.
cmb_recall_proactiveHigh-importance memories with no query (session start).
cmb_proactive_contextAgent-ready context packet + suggested queries.
cmb_ingestStore raw text; CMB extracts discrete facts.

Sessions

ToolPurpose
cmb_start_sessionOpen a session; returns bootstrap handoff (prior summary/open threads).
cmb_end_sessionClose with summary + open threads for cross-session resume.

Governance & History

ToolPurpose
cmb_correctReplace a memory's content without losing history (supersede).
cmb_forgetRetire a memory (bi-temporal close, never hard-deleted).
cmb_pinExempt a memory from automatic decay/pruning.
cmb_linkConnect two memories with a relation label.
cmb_promoteWiden a memory's visibility (session → repo → workspace).
cmb_timelineEvery version of a fact, oldest first, with validity windows.
cmb_whyWhy a fact is true — current answer + what it superseded.

Consolidation

ToolPurpose
cmb_consolidateDistill recurring episodic memories into one durable digest.
cmb_record_eventAppend a lightweight episodic log entry.

Analytics & Audit

ToolPurpose
cmb_context_savingsReport token savings (per token-counter).
cmb_statsMemory counts by type / workspace / session.
cmb_receiptsList hash-chained operation receipts.
cmb_verify_receiptsVerify receipt chain hashes + anchor.
cmb_export_receiptsExport full receipt payload + verification result.

Code Graph

ToolPurpose
cmb_index_repoParse a repo into the code symbol graph.
cmb_search_codeFind symbols with their callers.
cmb_code_pathShortest structural path between two symbols.
cmb_code_impactEstimate blast radius of a change.
cmb_export_code_graphExport graph JSON + Markdown report.

Schemas & Updates

ToolPurpose
cmb_ingest_postgres_schemaConvert Postgres tables/constraints into a schema memory + entity graph.
cmb_check_updateReport newer CMB release availability (disabled by default).
Recommended path: use cmb_recall_context with the smallest sufficient token_budget. Reserve cmb_recall for when complete memory bodies are needed.
