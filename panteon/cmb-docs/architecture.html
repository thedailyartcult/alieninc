Architecture

CMB is a self-hosted, single-binary Python service. The agent never talks to the engine directly — it goes through the MCP wrapper, which presents the branded cmb_* tool surface.

Data Model

  • Workspace — top-level tenant (e.g. alieninc, subsidiaries).
  • Repo — project scope inside a workspace.
  • Session — groups memories + stores handoff (summary, open threads).
  • Memory — the stored fact. Fields include scope, mtype, importance, valid_from/valid_to, provenance, subject_key (dedupe), pinned.
  • Receipt — hash-chained, content-free audit record of every mutation.

Security

  • Engine binds loopback only — no public network exposure.
  • MCP calls authenticated via CMB_API_TOKEN (env-injected, never committed).
  • Dashboard gated behind nginx + token/browser-session auth.
  • Memory is scoped; recall never crosses workspace boundaries.
Restart note: after changing the wrapper or plugin, restart the agent (opencode) so the new MCP process and plugin load.
