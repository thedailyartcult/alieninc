### Overview

Terranean is a dual-mode intelligence substrate built on the Panteon Philosophy. It exposes two complementary reasoning systems — **Etiology** and **Teleology** — that operate over the same underlying object graph, link types, and action framework.

- **Etiology** performs continuous causal reconstruction and forensic analysis of the operational environment.
- **Teleology** performs purpose/intent modeling and forward trajectory analysis of actors and systems.

Both systems are first-class citizens of the Ontology: they read from and write to Ontology objects, participate in action types, support functions, and can be invoked via the Ontology SDK, REST/gRPC endpoints, and AIP workflows.

---

### Core Data Model

Terranean extends the standard Ontology with a set of specialized object types and link types:

| Object / Link Type              | Description |
|--------------------------------|-------------|
| `CausalNode`                   | Represents an event, state, decision, or observation that participates in a causal chain. |
| `CausalEdge`                   | Directed, typed, weighted link between CausalNodes. Supports confidence, lag, and alternative-path metadata. |
| `CausalGraph`                  | Versioned, queryable subgraph (or full graph snapshot) of CausalNodes + CausalEdges for a given scope and time window. |
| `PurposeObject`                | Represents an inferred or declared goal / objective of an actor, organization, system, or process. |
| `PurposeTrajectory`            | Projected future state sequence derived from one or more PurposeObjects under a given constraint set. |
| `LeveragePoint`                | Actionable node or edge identified by Teleology as high-impact for altering a trajectory. |
| `EtiologyRun` / `TeleologyRun` | Execution records containing inputs, parameters, outputs, and provenance for auditability. |

All objects support standard Ontology features: properties, links, actions, functions, dynamic security, and time-series attachment.

### Terranean Etiology

**Purpose**: Reconstruct and maintain causal ancestry of the operational environment at scale.

#### Key Capabilities (current release)

- Continuous or on-demand causal graph construction from heterogeneous data sources (events, logs, sensor feeds, human reports, external intelligence).
- Multi-hop causal path discovery with confidence scoring and alternative-history ranking.
- Gap detection: surfaces missing CausalNodes or low-confidence edges that require additional collection or human adjudication.
- Counterfactual analysis: given a CausalGraph, evaluate the effect of intervening on specific nodes/edges.
- Forensic replay: reconstruct the state of the graph at any prior timestamp.
- Integration with Ontology Action Types for automated or human-in-the-loop enrichment.

#### Primary Interfaces

- `EtiologyService.reconstruct(scope, timeWindow, options)` → `CausalGraph`
- `EtiologyService.traceAncestry(nodeId, depth, filters)` → ranked list of causal paths
- `EtiologyService.counterfactual(graphId, interventions)` → projected graph deltas
- Object-backed functions and AIP Logic functions for embedding causal queries inside larger workflows.

#### Technical Notes

- CausalEdge weights and confidence are maintained as first-class properties and can be updated by downstream models or human operators.
- Graph materialization is incremental; full recomputation is available but expensive — prefer scoped or delta runs in production.
- Provenance is recorded on every CausalNode and CausalEdge for audit and model-retraining loops.

### Terranean Teleology

**Purpose**: Infer, represent, and project the purpose structures of actors and systems, then identify high-leverage interventions.

#### Key Capabilities (current release)

- Purpose inference from observed behavior, declared doctrine, resource allocation patterns, and communication artifacts.
- Explicit PurposeObject declaration and versioning (human or machine authored).
- Trajectory projection under configurable constraint sets (resource, temporal, doctrinal, environmental).
- LeveragePoint identification: ranks nodes/edges by estimated impact on shifting a trajectory toward or away from a desired end-state.
- Competitive purpose analysis: simultaneous modeling of multiple actors’ purpose structures and their interaction effects.
- Closed-loop integration with Etiology (causal history informs purpose inference; purpose trajectories can be validated against emerging causal evidence).

#### Primary Interfaces

- `TeleologyService.inferPurposes(actorScope, evidenceWindow, options)` → set of `PurposeObject`
- `TeleologyService.projectTrajectory(purposeIds, constraints, horizon)` → `PurposeTrajectory`
- `TeleologyService.identifyLeverage(trajectoryId, objective)` → ranked `LeveragePoint`s
- Support for batch and streaming modes; results written back as Ontology objects for downstream consumption.

#### Technical Notes

- PurposeObjects carry both structured goal representations and free-form rationales.
- Trajectory projections are stochastic; confidence bands and scenario ensembles are available.
- LeveragePoint scoring is extensible via custom functions registered in the Ontology.

### Cross-System Workflows

Common production patterns:

1. **Causal → Purpose loop**  
   Etiology reconstructs recent causal structure → Teleology updates purpose models → new trajectories are generated → actions are proposed.

2. **Purpose-guided collection**  
   Teleology identifies high-value unknown nodes → Etiology (or external collectors) prioritizes filling those causal gaps.

3. **Intervention simulation**  
   Proposed actions are expressed as interventions on the CausalGraph and/or modifications to PurposeObjects; both systems evaluate second-order effects.

All workflows are expressible as Ontology Action Types + Functions and can be orchestrated via AIP, Foundry Pipelines, or external orchestrators calling the Terranean APIs.
