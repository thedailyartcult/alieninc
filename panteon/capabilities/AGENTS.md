## Page Structure (mandatory)

1. `<link rel="stylesheet" href="../styles.css">`
2. Google Fonts Inter import
3. Inline `<style>` for page-specific overrides
4. SVG brand lockup
5. Announcement bar → Header → Platform Hero → Main Content → Footer
6. Scroll-handler script

## Content Sections

1. **Platform Hero**: tag (e.g., "Capability · AI + ML"), headline, description
2. **Platform Nav**: link to sibling capabilities
3. **Prose Section**: overview of the capability
4. **Core Capabilities**: 2x2 grid of architecture cards
5. **Editorial Callout**: single statement
6. **How It Works**: 3-step workflow
7. **CTA Section**: centered call-to-action

## Forbidden

- NO new fonts, colors, or layouts
- NO different footer or header structures
